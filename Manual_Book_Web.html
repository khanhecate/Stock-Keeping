BUKU PANDUAN PENGGUNA & ADMINISTRATOR

Sistem Manajemen Inventaris & Ruang Rapat Kantor Berbasis Web

Ringkasan Aplikasi: Perangkat lunak berbasis web on-premise yang dirancang untuk kantor internal guna mendata aset fisik, melacak peminjaman barang oleh karyawan, mencatat pengeluaran barang habis pakai (ATK), dan mengelola jadwal ruang rapat secara otomatis tanpa bentrok jadwal.

BAB I: PENDAHULUAN

1.1 Tentang Aplikasi

Aplikasi ini merupakan transformasi dari sistem desktop ke platform web intranet. Sistem ini memberikan kemudahan bagi seluruh karyawan di kantor karena tidak lagi membutuhkan proses instalasi Java atau software khusus di komputer klien. Cukup melalui web browser (Google Chrome, Microsoft Edge, Mozilla Firefox) yang terhubung ke jaringan Wi-Fi atau LAN kantor, seluruh modul dapat diakses secara cepat dan aman.

1.2 Kebutuhan Server (Komputer Host Kantor)

  • Sistem Operasi: Windows 10/11, Windows Server, atau Linux.
  • Runtime: Node.js versi 18 ke atas (disarankan v20 atau v24).
  • Database: MySQL 5.7+ atau MariaDB (dapat menggunakan XAMPP).
  • Konektivitas: Jaringan LAN / Wi-Fi kantor dengan alokasi IP statis pada komputer server.

BAB II: PANDUAN DEPLOYMENT DI SERVER LOKAL KANTOR

2.1 Persiapan Database MySQL

  1. Buka XAMPP Control Panel dan klik Start pada modul Apache dan MySQL.
  2. Buka browser dan buka http://localhost/phpmyadmin.
  3. Import file database dari direktori: web-app/database/schema.sql.
  4. Database inventory_db beserta seluruh tabel dan data awal (seed) akan otomatis dibuat.

2.2 Menjalankan Server Node.js

  1. Buka Terminal / Command Prompt / PowerShell.
  2. Masuk ke folder web-app: 
    cd d:\KAMPUS\Pemrograman_Visual\InventoryManagement\web-app
  3. Jalankan aplikasi dengan perintah: 
    npm start
  4. Terminal akan menampilkan alamat IP yang dapat diakses oleh komputer lain di jaringan LAN kantor: 
    ==========================================================
   SISTEM MANAJEMEN INVENTARIS & RUANGAN KANTOR (WEB)     
==========================================================
[Server] Berjalan di port : 3000
[Server] Akses Lokal      : http://localhost:3000
[Server] Akses Jaringan LAN Kantor:
   👉 http://192.168.1.15:3000
==========================================================

2.3 Mengizinkan Akses Firewall Windows

Jika komputer staf lain di kantor tidak bisa membuka tautan IP tersebut, pastikan Port 3000 diizinkan di Windows Defender Firewall (Inbound Rules) pada komputer server.

BAB III: FITUR UTAMA & PENGOPERASIAN

3.1 Dashboard Utama

Menampilkan metrik bisnis penting:

  • Total Jenis Aset: Jumlah macam barang yang terdaftar di perusahaan.
  • Total Stok Fisik: Akumulasi unit barang riil di seluruh gudang/ruangan.
  • Aset Dipinjam: Jumlah barang yang saat ini sedang dibawa oleh PIC.
  • Rapat Hari Ini: Agenda pemakaian ruang rapat aktif.
  • Distribusi Kategori: Grafik komposisi inventaris.

3.2 Modul Master Data

Berfungsi untuk mengelola data inti referensi:

  • Data Aset: Menambah barang baru, mengisi spesifikasi, satuan, lokasi, dan vendor. Dilengkapi fitur Auto-Generate Barcode (misal: AST-2026-001).
  • Kategori: Membedakan tipe klasifikasi ASET (barang modal tahan lama) dan CONSUMABLE (barang habis pakai seperti ATK/kertas).
  • Ruang Rapat: Mengatur nama ruang pertemuan dan fasilitas penunjang.
  • Lokasi & Status: Mengatur lokasi penempatan fisik dan label status (Tersedia, Dipinjam, Rusak, Habis).

3.3 Modul Peminjaman & Pengembalian Aset

  1. Pilih menu Peminjaman Aset lalu klik + Catat Peminjaman Baru.
  2. Isi nama penanggung jawab (PIC), divisi kerja, pilih barang yang tersedia, tanggal pinjam, dan estimasi tanggal kembali.
  3. Klik Konfirmasi Peminjaman. Stok aset di sistem akan otomatis berkurang.
  4. Saat barang dikembalikan oleh PIC, cukup klik tombol 🔄 Kembalikan pada baris tabel peminjaman. Sistem otomatis mengembalikan stok ke gudang.

3.4 Modul Reservasi Ruang Rapat (Anti-Bentrok)

Sistem memiliki mekanisme cerdas Collision Detection. Ketika pengguna memilih ruangan, tanggal mulai, dan jam selesai, sistem langsung memvalidasi apakah jadwal tersebut bertabrakan dengan rapat lain yang sudah disetujui. Jika bentrok, sistem akan memberikan peringatan dan menolak reservasi ganda.

3.5 Modul Stock Opname (Audit Berkala)

Digunakan untuk audit fisik stok gudang secara periodik:

  1. Buka menu Stock Opname.
  2. Pilih barang yang disurvei, klik ⚖️ Sesuaikan Stok.
  3. Masukkan jumlah fisik riil hasil audit beserta catatan alasan selisih.
  4. Klik simpan. Jika stok menjadi 0, status otomatis berubah menjadi "Habis".

3.6 Pelaporan, Ekspor Excel & Cetak Dokumen

  • Ekspor Excel: Klik tombol 📥 Export Excel untuk mengunduh laporan rekapitulasi berformat .xlsx.
  • Cetak Dokumen Resmi (PDF): Klik tombol 🖨️ Cetak Fisik untuk membuka pratinjau surat resmi yang dilengkapi Kop Perusahaan, tanggal cetak, dan tanda tangan Mengetahui (GA/IT) serta Petugas.

BAB IV: PEMELIHARAAN & PENAMBAHAN KEBUTUHAN KANTOR

Aplikasi ini dirancang modular sehingga memudahkan penambahan fitur baru di masa depan (Future Enhancements):

  • Barcode Scanner Kamera HP: Pindai QR/Barcode langsung lewat kamera smartphone staf saat serah terima barang.
  • WhatsApp / Email Notification Gateway: Notifikasi pengingat otomatis sebelum batas waktu peminjaman barang berakhir.
  • Single Sign-On (Active Directory / Google Workspace): Integrasi login menggunakan akun email resmi perusahaan.
  • Multi-Branch: Pengelolaan inventaris untuk kantor yang memiliki lebih dari satu gedung/cabang.
